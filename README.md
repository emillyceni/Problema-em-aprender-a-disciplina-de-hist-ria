# Problema-em-aprender-a-disciplina-de-hist-ria
**Problema:** Crianças que possuem dificuldade em aprender a disciplina de história.

**Solução:** Jogo RPG onde ele ajuda essas crianças a aprender de forma lúdica e intuitiva, o jogo irá conter fases e cada fase seja um tipo de história, como por exemplo história do Brasil, Guerra Fria e assim por diante. O jogo também terá cores claras e simples para fácil entendimento e acessibilidade para pessoas com defienciência

# 🏰 AprendeRPG

## 📚 Sobre o projeto

O AprendeRPG é um jogo educativo no estilo RPG desenvolvido para auxiliar crianças com dificuldades no aprendizado da disciplina de História.

O projeto utiliza elementos de jogos, como missões, batalhas, personagens históricos, perguntas e recompensas, para tornar o aprendizado mais interativo e divertido.

## 🎯 Objetivo

O objetivo do AprendeRPG é tornar o aprendizado de História mais atrativo, utilizando a gamificação como ferramenta educacional.

## 🎮 Funcionalidades

- ⚔️ Batalhas com perguntas históricas
- 🗺️ Exploração de épocas históricas
- 📜 Missões educativas
- 👤 Personagens históricos
- 💡 Explicações após respostas incorretas
- 🏆 Sistema de recompensas
- 📊 Sistema de progresso
